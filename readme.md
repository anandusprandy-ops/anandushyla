Responsive dark portfolio for Anandu Shyla with 10 supplied artworks.

- `styles.css` — dark responsive design
- `script.js` — mobile menu, category filters, image lightbox
- `images/` — optimized copies of the 10 uploaded artworks plus `profile-photo.jpg`

## Publish for free with Netlify Drop
1. Download and extract `roddy1729-portfolio-with-works.zip`.
2. Open https://app.netlify.com/drop and sign in or create an account if prompted.
3. Upload the extracted `roddy1729-portfolio-with-works` folder (the folder containing `index.html`).
4. Netlify provides a public `*.netlify.app` address. Open it on your phone and test the WhatsApp, email and Instagram links.
